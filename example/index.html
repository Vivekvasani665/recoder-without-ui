Set up Google Drive (one time, ~3 minutes)

Google requires every app that saves to Drive to have its own Client ID. Your email address is not enough. Create one for free:

  1. Create a Google Cloud project (any name).
  2. Enable the Google Drive API → click Enable.
  3. Set up the consent screen → External → fill app name + your email. Under Audience → Test users, add your Gmail.
  4. Create an OAuth client ID → type Web application → under Authorized JavaScript origins add:
  5. Copy the Client ID it shows (ends in .apps.googleusercontent.com) and paste it below.
